# GR-11b Tags Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The user creates lightweight and annotated tags on any commit, sees local tags in a collapsible Tags section of the left column (filtered together with branches), jumps to a tag's commit, deletes a local tag, and pushes a tag to, or deletes it from, any configured remote. Tags keep showing in the commit graph for every tag the user creates or deletes. This closes GR-11.

**Architecture:** The core lists tags and deletes them with git2 (`refs/tags/*` read, `repo.tag_delete`), and creates them with the git CLI so `tag.gpgSign` is honoured (ADR 0001). An annotated tag gets its message on stdin through a stdin-capable runner, which is extracted from `commit/git_commit.rs` into `git_cli::capture_with_input` so commit and tag share one pipe-draining implementation. Push and remote delete follow the GR-7 prepare-then-run pattern: `prepare_tag_push` / `prepare_remote_tag_delete` validate under the session lock and return `TagPush` / `TagPushDelete`, which run `git push` after the lock is released. The push runner and its `PushFailed` mapping move from `PushDelete::run` into `remote::run_push`, which all three pushes share. The log cache fingerprint already hashes every ref under `refs/`, and the watcher already reports `refs/tags` and `packed-refs`, so the graph labels follow without core changes. The front end adds typed IPC wrappers, `features/tags/` (`useTags`, `useTagActions`, `TagsPanel`, `TagRow`, `TagFeedback`, `CreateTagDialog`, copy and the HEAD-commit helper), moves the branch filter text into the workspace store as `refsFilter` (shared by `BranchesPanel` and `TagsPanel`), persists `tagsCollapsed` in `layoutPrefs`, adds **Create tag here…** to the graph's commit menu, and mounts `TagsPanel` below `StashesPanel`.

**Tech Stack:** Rust 2024 + git2 0.20.4 (`default-features = false`), system git CLI (behaviour verified with git 2.43.0), Tauri 2, React 19 + TypeScript, TanStack Query 5, zustand (+ `persist`), Vitest + Testing Library + happy-dom.

**Spec:** `docs/superpowers/specs/2026-10-20-gr11b-tags-design.md`

## Global Constraints

- Tests come first and are written by the test role. The developer role never edits test files, including `tests/common/mod.rs` in both crates and `src/test/*` fixtures (CLAUDE.md).
- Only `src/lib/ipc` imports `@tauri-apps/api/*` (ESLint-enforced). `git2` stays `default-features = false`. No direct `tokio`. Blocking work runs through `run_blocking`. `git-real-core` has no Tauri dependency.
- Backends (spec §2): `list_tags`, `delete_tag` and both `prepare_*` use git2. `create_tag` runs the git CLI. `TagPush::run` / `TagPushDelete::run` run the git CLI after `with_session` returns.
- argv shapes, everything after `-C <workdir>`, each a separate element: annotated create `tag -a --cleanup=whitespace -F - <name> <oid>` with the message on stdin; lightweight create `tag --no-sign <name> <oid>` (see Deviations); push `push <remote> refs/tags/<name>`; remote delete `push <remote> --delete tags/<name>`. `<oid>` is the resolved commit's full 40-hex id, never the caller's string. `<name>` and `<remote>` are validated before they reach argv, so no `--` is used.
- Checks, in order. `create_tag(name, oid, message)`: `validate_tag_name(name)` → `InvalidTagName`; `refs/tags/<name>` exists → `TagExists`; `revision::resolve_commit(repo, oid)` → `CommitNotFound`; `Some(m)` with `m.trim().is_empty()` → `EmptyMessage`; then git, whose non-zero exit is `OperationFailed { verb: "tag", .. }`. `delete_tag(name)`: a name that fails `validate_tag_name` or has no `refs/tags/<name>` → `TagNotFound`. `prepare_tag_push` / `prepare_remote_tag_delete(remote, name)`: remote first (leading `-` or unknown → `RemoteNotFound`), then the local tag (`TagNotFound`).
- Tag name rule: `!name.contains('\0') && !name.starts_with('-') && git2::Tag::is_valid_name(name)`. The NUL check comes first because `Tag::is_valid_name` unwraps a `CString` and would panic.
- `TagList.tags`: every `refs/tags/*` ref (loose and packed, names with `/` included) that peels to a commit; newest first by `time`, ties by `name` ascending. `time` is the outermost tag object's tagger time, or the peeled commit's committer time for a lightweight tag (or an annotated tag without a tagger). `subject` is the first line of the outermost tag's message, trimmed, `None` when blank or lightweight. `remotes` is `repo.remotes()`, UTF-8 names only, sorted.
- New `GitError` (Display text): `InvalidTagName(String)` "{0} is not a valid tag name", `TagExists(String)` "a tag named {0} already exists", `TagNotFound(String)` "no tag named {0}". New `AppErrorKind` / TS kinds: `invalidTagName`, `tagExists`, `tagNotFound`. Reused: `CommitNotFound`, `EmptyMessage`, `OperationFailed`, `RemoteNotFound`, `PushFailed`.
- Tauri commands (JS args camelCase): `list_tags {id}` → `TagList`; `create_tag {id, name, oid, message}` (`message: string | null`) → `void`; `delete_tag {id, name}`; `push_tag {id, remote, name}`; `delete_remote_tag {id, remote, name}`.
- Query key `queryKeys.tags(id) = ["repo", id, "tags"]` (under the repo prefix, so repo-changed refreshes it). Mutation key `mutationKeys.tag(id) = ["tag", id]`. Every tag action invalidates `queryKeys.tags(id)` on settle (success and failure, so a `tagNotFound` refetches the list); `create` and `remove` also invalidate `queryKeys.log(id)`.
- Workspace: `refsFilter: Record<RepoId, string>`, `setRefsFilter(repoId, text)`, forgotten by `clear(repoId)`. The filter is "active" when `text.trim() !== ""`, the same rule `filterBranches` and `filterTags` apply. The filter now survives switching tabs (it is per repo, no longer per mounted panel).
- `layoutPrefs`: `tagsCollapsed: boolean` (default `true`), `setTagsCollapsed(collapsed)`, persisted in `git-real.layoutPrefs` beside the widths. A stored state from before GR-11b has no `tagsCollapsed` and keeps the default.
- Copy (verbatim, spec §5): filter label `Filter branches and tags`; header `Tags (n)` / `Tags (m of n)`; `Create tag…` (the **+** accessible name); `Make a commit first`; `No tags`; `No matches`; `Pushed ‹name› to ‹remote›.`; `Deleted ‹name› from ‹remote›.`; `Tag ‹name› no longer exists; the list has been refreshed.`; menu `Copy name`, `Push to ‹remote›`, `Delete from ‹remote›…`, `Delete tag…`, and with no remotes `Push to remote` / `Delete from remote…` with title `No remotes configured`; dialog `Create tag on ‹short oid›`, `Name`, `Annotated`, `Message`, `Cancel`, `Create`; inline errors `‹name› is not a valid tag name.`, `A tag named ‹name› already exists.`, `That commit no longer exists.`, `Enter a message for an annotated tag.`, and git's text for `operationFailed`; confirms `Delete tag ‹name›?` / `The tag is removed from this repository only.` / `Delete` and `Delete tag ‹name› from ‹remote›?` / `Others who already fetched it keep their copy.` / `Delete`; graph item `Create tag here…`. ## Review Focus

1. A lightweight create must not be turned into a signed annotated tag by `tag.gpgSign=true`. With that config, plain `git tag <name> <oid>` opens the editor and fails with "fatal: no tag message?" (verified, git 2.43), so the argv carries `--no-sign`, while the annotated path still honours signing (Task 1 tests `create_lightweight_tag_ignores_tag_gpg_sign` and `create_annotated_tag_honours_tag_gpg_sign_and_reports_its_stderr`).
2. git accepts a blank annotated message: `git tag -a --cleanup=whitespace -F -` with only whitespace on stdin exits 0 and stores an empty annotated tag (verified). The core must refuse it with `EmptyMessage` before git runs (Task 1 test `create_annotated_tag_with_a_blank_message_is_empty_message_and_creates_nothing`).
3. A tag name never reaches argv unvalidated, and validation never panics: a leading `-` and a NUL byte are `InvalidTagName`, and git is not run (Task 1 tests `create_tag_with_a_nul_byte_is_invalid_tag_name` and, in `cli_argv.rs`, `create_tag_with_a_leading_dash_runs_no_git`).
4. Remote delete sends `tags/<name>`: it must never delete a remote branch of the same name, and a tag the remote lacks must fail with "remote ref does not exist" instead of reporting success (Task 1 tests `delete_remote_tag_never_removes_a_branch_with_the_same_name` and `delete_remote_tag_missing_on_the_remote_is_push_failed`).
5. While the shared filter has text, the Tags list is shown even when collapsed, the header reads `Tags (m of n)`, and the stored `tagsCollapsed` preference is untouched (Task 3 test `should show the matching tags while filtering even when collapsed, without changing the preference`).

## Deviations from spec

- **Lightweight create runs `git tag --no-sign <name> <oid>`**, not `git tag <name> <oid>`. With `tag.gpgSign=true`, git treats a plain `git tag <name>` as a request for a signed annotated tag, launches `GIT_EDITOR` (stdin is closed) and exits 128 with "fatal: no tag message?" (verified with git 2.43.0). `--no-sign` keeps the user's explicit "Annotated off" choice. The annotated path is unchanged and still signs when `tag.gpgSign` is set.
- **`delete_tag`, `prepare_tag_push` and `prepare_remote_tag_delete` report a name that is not a valid tag name as `TagNotFound`**, not `InvalidTagName`. Such a tag cannot exist, and `find_reference` on an invalid refname fails with a libgit2 `InvalidSpec` error that would otherwise surface as `git`. The check also keeps a leading `-` out of the push argv.
- **The stdin runner is shared with commit.** The spec only says the message goes on stdin. The writer thread and EPIPE handling in `commit/git_commit.rs` move into `git_cli::capture_with_input`, and `git_commit::run` calls it. The existing commit tests (hook failure before git reads stdin, large messages) pin the behaviour.
- **`PushDelete::run`'s push and failure mapping move to `remote::run_push`**, shared by `PushDelete`, `TagPush` and `TagPushDelete`. The existing `cli_argv.rs` push tests pin the argv and the `PushFailed` fields.
- **The remote check in `refs/mod.rs` becomes `RepoSession::ensure_remote`** (private to `refs`, visible to its child `refs::tags`), used by `remote_branch_ref` and by both tag `prepare_*` methods.
- **`filterTags` lives in `src/features/branches/branchFilter.ts`** beside `filterBranches`, sharing one private matcher, so the two lists can never disagree about a match.
- **The + button and the dialog need HEAD's full oid**, because the core accepts only a 40-hex commit id. `headCommit(list: BranchList | undefined)` derives it from the branch list the panel already loads: the detached oid, the `isHead` local branch's oid, or `null` (unborn or loading).
- **The Tags toggle keeps working while the filter has text.** It flips the stored preference, and `aria-expanded` reports what is shown (`true` while filtering). The new preference takes effect when the filter is cleared.
- **`TagEntry.subject` is trimmed and `None` when blank.** `--cleanup=whitespace` keeps leading spaces on the first line (verified: input `"\n  Subject  \n…"` stores `"  Subject\n…"`).
- **Test helpers turn tag signing off.** `configure_identity` in both crates' `tests/common` also sets `tag.gpgSign=false`, so a developer's global config never signs test tags. The test role makes this change.

//! Tag list, create, delete, push and remote delete (GR-11b), against real
//! temp repositories, a local bare repository as the remote (no network) and
//! the system git CLI.

mod common;

use std::path::{Path, PathBuf};

use git_real_core::{GitError, RepoSession, TagEntry};
use git2::Repository;
use tempfile::TempDir;

/// A repo with README.md committed, an identity, signing off, and an open session.
fn repo() -> (TempDir, PathBuf, RepoSession) {
    let (dir, path) = common::temp_repo_with_commit();
    common::configure_identity(&path);
    let session = RepoSession::open(&path).unwrap();
    (dir, path, session)
}

fn head(path: &Path) -> String {
    Repository::open(path).unwrap().head().unwrap().target().unwrap().to_string()
}

/// A repo whose `origin` is a local bare clone; returns (dirs, path, bare, session).
fn remote_repo() -> (TempDir, TempDir, PathBuf, PathBuf, RepoSession) {
    let (dir, path) = common::temp_repo_with_commit();
    common::configure_identity(&path);
    let head_name = common::head_branch_name(&path);
    let (bare_dir, bare) = common::temp_bare_clone(&path);
    common::add_remote_and_fetch(&path, &bare, &head_name);
    let session = RepoSession::open(&path).unwrap();
    (dir, bare_dir, path, bare, session)
}

/// The commit `refs/tags/<name>` peels to in `repo_path`, if the tag exists.
fn tag_commit(repo_path: &Path, name: &str) -> Option<String> {
    let repo = Repository::open(repo_path).unwrap();
    let r = repo.find_reference(&format!("refs/tags/{name}")).ok()?;
    Some(r.peel_to_commit().unwrap().id().to_string())
}

fn entry<'a>(tags: &'a [TagEntry], name: &str) -> &'a TagEntry {
    tags.iter().find(|t| t.name == name).unwrap_or_else(|| panic!("no {name} in {tags:?}"))
}

/// An executable that prints `gpg-boom` on stderr and exits 2.
#[cfg(unix)]
fn failing_gpg(dir: &Path) -> PathBuf {
    use std::os::unix::fs::PermissionsExt;
    let p = dir.join("fake-gpg");
    std::fs::write(&p, "#!/bin/sh\necho gpg-boom >&2\nexit 2\n").unwrap();
    std::fs::set_permissions(&p, std::fs::Permissions::from_mode(0o755)).unwrap();
    p
}

```rust
/// Runs `cmd` with `input` on stdin and stdout and stderr captured.
///
/// stdin is written on its own thread while the output drains, so neither
/// pipe can fill up and block both processes (a hook can print a lot before
/// git reads its input). git may exit before reading at all (a failing hook);
/// the resulting EPIPE is not the error worth reporting.
pub(crate) fn capture_with_input(cmd: &mut Command, input: &[u8]) -> std::io::Result<Output> {
    let mut child = cmd
        .stdin(Stdio::piped())
        .stdout(Stdio::piped())
        .stderr(Stdio::piped())
        .spawn()?;
    let mut stdin = child
        .stdin
        .take()
        .ok_or_else(|| io::Error::other("child stdin was not captured"))?;
    let (written, output) = thread::scope(|s| {
        let writer = s.spawn(move || match stdin.write_all(input) {
            Err(e) if e.kind() == io::ErrorKind::BrokenPipe => Ok(()),
            result => result, // dropping `stdin` closes it, so git sees EOF
        });
        let output = child.wait_with_output();
        (writer.join(), output)
    });
    let output = output?;
    written.map_err(|_| io::Error::other("the stdin writer thread panicked"))??;
    Ok(output)
}
```

//! Tags: listed and deleted with git2; created through `git tag` so
//! `tag.gpgSign` is honoured (signing is CLI-only, ADR 0001); pushed and
//! deleted on a remote through `git push` after the session lock is released.

use git2::{Reference, Repository, Tag};

use super::is_not_found;
use crate::error::GitError;
use crate::git_ops::{self, operation_failed};
use crate::git_cli;
use crate::model::{TagEntry, TagList};

use crate::revision::resolve_commit;

/// Names git accepts for `refs/tags/<name>` that can never be read as a flag.
fn validate_tag_name(name: &str) -> Result<(), GitError> {
    // `Tag::is_valid_name` unwraps a CString, so a NUL byte must be refused first.
    if name.contains('\0') || name.starts_with('-') || !Tag::is_valid_name(name) {
        return Err(GitError::InvalidTagName(name.to_owned()));
    }
    Ok(())
}

impl RepoSession {
    /// Local tags that peel to a commit, newest first, and the configured remotes.
    pub fn list_tags(&self) -> Result<TagList, GitError> {
        let repo = self.repo();
        let mut tags = Vec::new();
        for reference in repo.references_glob("refs/tags/*")? {
            if let Some(entry) = tag_entry(repo, &reference?) {
                tags.push(entry);
            }
        }
        tags.sort_by(|a, b| b.time.cmp(&a.time).then_with(|| a.name.cmp(&b.name)));
        let mut remotes: Vec<String> = repo.remotes()?.iter().flatten().map(str::to_owned).collect();
        remotes.sort();
        Ok(TagList { tags, remotes })
    }

    /// `git tag -a --cleanup=whitespace -F - <name> <oid>` with `message` on
    /// stdin, or `git tag --no-sign <name> <oid>` without one.
    pub fn create_tag(&self, name: &str, oid: &str, message: Option<&str>) -> Result<(), GitError> {
        validate_tag_name(name)?;
        if self.repo().find_reference(&tag_ref(name)).is_ok() {
            return Err(GitError::TagExists(name.to_owned()));
        }
        let target = resolve_commit(self.repo(), oid)?.id().to_string();
        // git 2.43 stores a blank annotated message without complaint, so it is refused here.
        if message.is_some_and(|m| m.trim().is_empty()) {
            return Err(GitError::EmptyMessage);
        }
        let (git, workdir) = self.git()?;
        let output = match message {
            Some(m) => git_ops::run_with_input(
                &git, workdir, "tag",
                &["-a", "--cleanup=whitespace", "-F", "-", name, &target],
                m.as_bytes(),
            )?,
            // `--no-sign`: with tag.gpgSign set, a plain `git tag` would open an editor for a signed annotated tag.
            None => git_ops::run(&git, workdir, "tag", &["--no-sign", name, &target], &[])?,
        };
        if output.status.success() { Ok(()) } else { Err(operation_failed("tag", &output)) }
    }

    pub fn delete_tag(&self, name: &str) -> Result<(), GitError> {
        self.find_tag(name)?;
        self.repo().tag_delete(name)?;
        Ok(())
    }

    /// Validates a tag push and returns it, to run after the session lock is released.
    pub fn prepare_tag_push(&self, remote: &str, name: &str) -> Result<TagPush, GitError> {
        self.ensure_remote(remote)?;
        self.find_tag(name)?;
        Ok(TagPush::new(git_cli::locate()?, self.workdir()?.to_path_buf(), remote.to_owned(), name.to_owned()))
    }

    /// As [`Self::prepare_tag_push`]; the local tag must exist (local tags only, spec §2).
    pub fn prepare_remote_tag_delete(&self, remote: &str, name: &str) -> Result<TagPushDelete, GitError> {
        self.ensure_remote(remote)?;
        self.find_tag(name)?;
        Ok(TagPushDelete::new(git_cli::locate()?, self.workdir()?.to_path_buf(), remote.to_owned(), name.to_owned()))
    }

    /// The local `refs/tags/<name>`; a name that cannot be a tag is `TagNotFound` too.
    fn find_tag(&self, name: &str) -> Result<Reference<'_>, GitError> {
        let not_found = || GitError::TagNotFound(name.to_owned());
        validate_tag_name(name).map_err(|_| not_found())?;
        match self.repo().find_reference(&tag_ref(name)) {
            Ok(r) => Ok(r),
            Err(e) if is_not_found(&e) => Err(not_found()),
            Err(e) => Err(e.into()),
        }
    }
}

fn tag_ref(name: &str) -> String {
    format!("refs/tags/{name}")
}

/// `None` for a tag that does not peel to a commit (a tree or blob), as the graph skips it.
fn tag_entry(repo: &Repository, reference: &Reference<'_>) -> Option<TagEntry> {
    let name = reference.name_bytes().strip_prefix(b"refs/tags/")?;
    let commit = reference.peel_to_commit().ok()?;
    let tag = reference.target().and_then(|oid| repo.find_tag(oid).ok());
    let commit_time = commit.time().seconds();
    let (annotated, subject, time) = match &tag {
        Some(t) => (true, subject_of(t.message_bytes()), t.tagger().map_or(commit_time, |s| s.when().seconds())),
        None => (false, None, commit_time),
    };
    Some(TagEntry {
        name: String::from_utf8_lossy(name).into_owned(),
        target: commit.id().to_string(),
        annotated,
        subject,
        time,
    })
}

fn subject_of(message: Option<&[u8]>) -> Option<String> {
    let text = String::from_utf8_lossy(message?);
    let first = text.lines().next()?.trim();
    (!first.is_empty()).then(|| first.to_owned())
}

/** A case-insensitive substring test for `query`, or null when the query is blank. */
function matcher(query: string): ((s: string) => boolean) | null {
  const q = query.trim().toLowerCase();
  return q === "" ? null : (s) => s.toLowerCase().includes(q);
}

/** Whether `query` filters anything; the refs column's single rule. */
export const isFiltering = (query: string): boolean => matcher(query) !== null;

// filterBranches: `const hit = matcher(query); if (hit === null) return list;` then as today.

/** Tags whose name contains the query, case-insensitively, in their order; a blank query returns `tags` itself. */
export function filterTags(tags: TagEntry[], query: string): TagEntry[] {
  const hit = matcher(query);
  return hit === null ? tags : tags.filter((t) => hit(t.name));
}

```ts
type TagRequest =
  | { action: "create"; name: string; oid: string; message: string | null }
  | { action: "remove"; name: string }
  | { action: "push" | "deleteRemote"; remote: string; name: string };

function execute(repoId: RepoId, req: TagRequest): Promise<void> {
  switch (req.action) {
    case "create":
      return createTag(repoId, req.name, req.oid, req.message);
    case "remove":
      return deleteTag(repoId, req.name);
    case "push":
      return pushTag(repoId, req.remote, req.name);
    case "deleteRemote":
      return deleteRemoteTag(repoId, req.remote, req.name);
  }
}

export function useTagActions(repoId: RepoId): UseTagActions {
  const queryClient = useQueryClient();
  const [status, setStatus] = useState<TagStatus | null>(null);
  const [lastName, setLastName] = useState<string | null>(null);
  // Counted here as well: `useIsMutating` updates a tick after mutateAsync starts.
  const [busy, setBusy] = useState(0);
  const elsewhere = useIsMutating({ mutationKey: mutationKeys.tag(repoId) }) > 0;
  const mutation = useMutation<void, AppError, TagRequest>({
    mutationKey: mutationKeys.tag(repoId),
    mutationFn: (req) =>
      execute(repoId, req).catch((e: unknown) => {
        throw toAppError(e);
      }),
    // Runs on failure too: a vanished tag needs the new list.
    onSettled: (_d, _e, req) =>
      Promise.all([
        queryClient.invalidateQueries({ queryKey: queryKeys.tags(repoId) }),
        req.action === "create" || req.action === "remove"
          ? queryClient.invalidateQueries({ queryKey: queryKeys.log(repoId) })
          : undefined,
      ]),
  });
  const { mutateAsync } = mutation;

  const run = (req: TagRequest): Promise<AppError | null> => {
    setStatus(null);
    setLastName(req.name);
    setBusy((n) => n + 1);
    return mutateAsync(req)
      .then(
        () => {
          if (req.action === "push" || req.action === "deleteRemote")
            setStatus({
              kind: req.action === "push" ? "pushed" : "deletedRemote",
              name: req.name,
              remote: req.remote,
            });
          return null;
        },
        (e: AppError) => e,
      )
      .finally(() => setBusy((n) => n - 1));
  };

  return {
    create: (name, oid, message) => run({ action: "create", name, oid, message }),
    remove: (name) => run({ action: "remove", name }),
    push: (remote, name) => run({ action: "push", remote, name }),
    deleteRemote: (remote, name) => run({ action: "deleteRemote", remote, name }),
    pending: busy > 0 || elsewhere,
    error: mutation.error,
    status,
    lastName,
    clearError: mutation.reset,
    clearStatus: () => setStatus(null),
  };
}
```
