# GR-11a Stash Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The user stashes the working tree (optional message, optional untracked files), sees their stashes in the left column below the branches, inspects a stash's tracked and untracked files and diffs in the right column, and applies, pops or drops a stash (drop confirms). A conflicting apply or pop leaves the conflicted files in the Changes panel, where the GR-10b editor resolves them.

**Architecture:** The core reads the stash list from the `refs/stash` reflog and a stash's files through the existing `commit_files` logic, both with git2. It writes with the git CLI through the existing `merge::git_ops::run` (ADR 0001): `git stash push|apply|pop|drop`. Every write that names a stash checks first that `stash@{n}` still resolves to the caller's oid. "Nothing to stash" is found by comparing the `refs/stash` target before and after the push. A conflicting apply leaves no `MERGE_HEAD` (verified with git 2.43: the repository state stays `Clean`), so stash results are classified by their own rule, "non-zero exit plus index conflicts", not by `RepoSession::outcome`, which needs a non-clean state. The front end adds typed IPC wrappers, three hooks under `src/features/stash/`, a `selectedStash` workspace slot kept mutually exclusive with `selectedCommit`, a `StashesPanel` below `BranchesPanel`, a `StashDialog`, a **Stash…** button in the Changes panel, and a `StashSummary` in the right column. The existing `DetailPane` shows the diffs through `DiffScope::Commit`.

**Tech Stack:** Rust 2024 + git2 0.20 (`default-features = false`), system git CLI, Tauri 2, React 19 + TypeScript, TanStack Query 5, zustand, Vitest + Testing Library + happy-dom.

**Spec:** `docs/superpowers/specs/2026-10-20-gr11a-stash-design.md`

## Global Constraints

- Tests come first and are written by the test role. The developer role never edits test files (CLAUDE.md).
- Only `src/lib/ipc` imports `@tauri-apps/api/*` (ESLint-enforced). `git2` stays `default-features = false`. No direct `tokio`. Blocking work runs through `run_blocking`. `git-real-core` has no Tauri dependency.
- Reads use git2: `list_stashes` reads `repo.reflog("refs/stash")` (entry 0 is the newest, so entry _n_ is `stash@{n}`), and `stash_files` uses `commit_files`. Writes use git: `git_ops::run(&git, workdir, "stash", args, &[])`.
- argv shapes, everything after `-C <workdir>` (strings are separate argv elements): `stash push [--include-untracked] [-m <message>]`, `stash apply stash@{<n>}`, `stash pop stash@{<n>}`, `stash drop stash@{<n>}`. `<n>` is the code's `u32` formatted with `format!("stash@{{{index}}}")` and is never a caller string. A message that is empty or only whitespace counts as no message. A non-blank message is passed unchanged as the element after `-m`.
- Order of checks: `stash_push`: unborn (`UnbornHead`), then operation in progress (`OperationInProgress`), then index conflicts (`UnresolvedConflicts`), then git. `stash_apply`/`stash_pop`: index+oid guard (`StaleStash`), then operation in progress, then index conflicts, then git. `stash_drop`: guard, then git.
- Classification: push returns `NothingToStash` on exit 0 when the `refs/stash` target is unchanged. Apply/pop: exit 0 is `Applied`. A non-zero exit with conflicts in the freshly read index is `Conflicts`. Any other non-zero exit, from any verb, is `OperationFailed { verb: "stash", .. }` carrying stdout and stderr.
- Branch parsing: strip `WIP on ` or `On `, then take the text before the first `:`. `(no branch)` and messages that do not parse give `None`.
- New `GitError`: `NothingToStash` ("there are no local changes to stash"), `StaleStash` ("the stash list changed; reload it"). New `AppErrorKind` / TS kinds: `nothingToStash`, `staleStash`.
- Tauri commands (JS args camelCase): `list_stashes {id}`, `get_stash_files {id, oid}`, `stash_push {id, message, includeUntracked}`, `stash_apply {id, index, oid}`, `stash_pop {id, index, oid}`, `stash_drop {id, index, oid}`.
- Query keys: `queryKeys.stashes(id) = ["repo", id, "stashes"]` (under the repo prefix, so repo-changed refreshes it) and `queryKeys.stashFiles(id, oid) = ["repoImmutable", id, "stashFiles", oid]` (a stash commit never changes). Stash mutations invalidate `queryKeys.repo(id)` on settle, which covers stashes, status, log and operation.
- Workspace: `selectStash(repo, oid)` with a non-null oid also sets `selectedCommit[repo] = null`. `selectCommit(repo, oid)` with a non-null oid also sets `selectedStash[repo] = null`. Null calls touch only their own slot. `clear(repo)` forgets `selectedStash`.
- Gates. Push (`+` and **Stash…**): disabled with no title while status or operation state is loading. Otherwise disabled with the first matching title: `Make a commit first` (`status.headUnborn`), `Finish or abort the current operation first` (`IN_PROGRESS_TITLE`), `Resolve all conflicts first` (any `entry.conflicted`), `No changes to stash` (no entries). Apply/Pop: disabled while loading, then `IN_PROGRESS_TITLE`, then `Resolve all conflicts first`. Drop: only disabled while an action is pending.
- Copy (verbatim, spec §5–6): `Stashes`; `Stash changes…` (the **+** button's accessible name); `No stashes`; `Apply`; `Pop`; `Drop…`; `Drop stash@{n}?`; `This can't be undone.`; `Drop`; `Applied with conflicts. Resolve them in Changes.`; the pop suffix ` The stash was kept; drop it once resolved.`; `The stash list changed; it has been refreshed.`; `Make a commit first`; `No changes to stash`; dialog `Message`, `Include untracked files`, `Cancel`, `Stash`, `No local changes to stash.`; Changes panel button `Stash…`; summary header `stash@{n}` and `Close`; file groups `Changes` and `Untracked`. Plan-chosen copy (not in the spec): dialog title `Stash changes`, loading lines `Loading stashes…` / `Loading stash…`, untracked marker `untracked`, `Dismiss`, the Close button's `aria-label="Close stash details"`, and the working label `Working…` taken from `PromptDialog`.

## Review Focus

1. A detached stash reads `WIP on (no branch): …` and must give `branch: None`, not `Some("(no branch)")`. A hand-stored message that does not parse also gives `None` (Task 1 tests `list_stashes_detached_entry_has_no_branch` and `list_stashes_unparseable_message_has_no_branch`).
2. The guard runs before the operation-state check. A shifted index must fail with `StaleStash` and touch nothing, even during a merge (Task 1 tests `stash_drop_with_a_shifted_index_is_stale_and_drops_nothing` and `stash_apply_checks_the_guard_before_the_operation_state`).
3. A conflicting apply leaves the repository state `Clean`, so it must be classified by index conflicts alone. An index that already had conflicts must be refused before git runs, or git's refusal would be misread as `Conflicts` (Task 1 tests `stash_apply_conflict_reports_conflicts_and_keeps_the_stash` and `stash_apply_with_existing_index_conflicts_is_unresolved_conflicts`).
4. An untracked-only tree pushed without `--include-untracked` makes git exit 0 with "No local changes to save". That must surface as `NothingToStash`, found by comparing refs. The message must reach git as one argv element even when it starts with `-` (Task 1 tests `stash_push_untracked_only_without_flag_is_nothing_to_stash` and, in `cli_argv.rs`, `stash_push_passes_the_message_as_one_argv_element`).
5. Selecting a stash clears the selected commit and the reverse. A selected stash that leaves the list (popped, dropped, changed in a terminal) clears the selection and any file opened from it, and the right column returns to Changes (Task 2 test `selectStash with an oid clears the selected commit`, Task 4 test `should clear the selection when the stash leaves the list`).

## Deviations from spec

- **Apply/pop also refuse on existing index conflicts** (`UnresolvedConflicts`), after the operation-in-progress check. The spec's classification rule ("non-zero and the index has conflicts → `Conflicts`") would otherwise report git's refusal on an already-conflicted index as a fresh conflict. In the UI, Apply/Pop are disabled with `Resolve all conflicts first` in that case, as push already is.
- **The stash argv test lives in `crates/git-real-core/tests/cli_argv.rs`**, not `tests/stash.rs`. That binary already installs the scripted stand-in `git` on `PATH` once per process. Putting it in `stash.rs` would swap `PATH` under the real-git tests.
- **The Changes panel's Stash… button sits in a new panel toolbar row** above the sections, not in a section header. The panel has no panel-level header, and the Staged/Unstaged headers that hold Stage all / Unstage all are not rendered when there are no changes. In that state the button must still show, disabled, with `No changes to stash` (walk step 7).
- **`StashDialog` owns its own `useStashActions` instance.** It does not take one from its opener, so a push error shows only in the dialog and never leaks into the panel's or the Changes panel's error area. Panel, summary and dialog still share the one hook.
- **When a stash vanishes, a file opened from it is cleared too:** `selected[repo]` is cleared if its scope is `{ commit }` of the stash oid or its untracked oid. Otherwise the centre pane would keep showing a diff of a stash that no longer exists. The Close button keeps CommitSummary's behaviour and clears only the stash selection.
- **The core helpers become crate-visible:** `merge::git_ops` becomes `pub(crate) mod`, and `RepoSession::{ensure_clean, ensure_born, git}` and `merge::operation_failed` become `pub(crate)`. The spec lists them as reused. They are private today, and `stash` is a sibling module, not a child of `merge`.

```rust
//! Stash list, files, push, apply, pop and drop (GR-11a), against real temp
//! repositories and the system git CLI.

mod common;

use std::path::{Path, PathBuf};

use git_real_core::{ChangeKind, GitError, OperationState, RepoSession, StashEntry, StashOutcome};
use git2::Repository;
use tempfile::TempDir;

/// A repo with README.md committed, an identity, and an open session.
fn repo() -> (TempDir, PathBuf, RepoSession) {
    let (dir, path) = common::temp_repo_with_commit();
    common::configure_identity(&path);
    let session = RepoSession::open(&path).unwrap();
    (dir, path, session)
}

fn read(path: &Path, rel: &str) -> String {
    std::fs::read_to_string(path.join(rel)).unwrap()
}

fn stash_tip(path: &Path) -> Option<git2::Oid> {
    Repository::open(path).unwrap().refname_to_id("refs/stash").ok()
}

fn is_clean(path: &Path) -> bool {
    common::run_git_ok(path, &["status", "--porcelain"]).stdout.is_empty()
}

/// Edits README.md and stashes it with `git stash push -m <msg>`; returns the new entry 0.
fn stash_readme(path: &Path, session: &RepoSession, content: &str, msg: &str) -> StashEntry {
    common::write_file(path, "README.md", content);
    common::run_git_ok(path, &["stash", "push", "-m", msg]);
    session.list_stashes().unwrap().remove(0)
}

/// Stash README "stashed\n", then commit README "committed\n": applying the stash conflicts.
fn conflicting_stash(path: &Path, session: &RepoSession) -> StashEntry {
    let entry = stash_readme(path, session, "stashed\n", "wip");
    common::commit_file(path, "README.md", "committed\n", "change readme");
    entry
}
```

```rust
//! Stashes: the list and a stash's files are read with git2 from the
//! `refs/stash` reflog; push, apply, pop and drop run the git CLI so hooks
//! and conflict output match the command line (ADR 0001).
//!
//! A write names a stash by index and full oid and fails with `StaleStash`
//! unless `stash@{n}` still is that oid. A conflicting apply leaves no
//! operation in progress (no MERGE_HEAD), so results are classified by the
//! index alone.

use std::process::Output;

use git2::{ErrorCode, Oid};

use crate::error::GitError;
use crate::merge::{git_ops, operation_failed};
use crate::model::{StashEntry, StashFiles, StashOutcome};
use crate::repo::RepoSession;

const STASH_REF: &str = "refs/stash";

impl RepoSession {
    /// The stashes, newest first; entry n is `stash@{n}`.
    pub fn list_stashes(&self) -> Result<Vec<StashEntry>, GitError> {
        let repo = self.repo();
        match repo.find_reference(STASH_REF) {
            Ok(_) => {}
            Err(e) if e.code() == ErrorCode::NotFound => return Ok(Vec::new()),
            Err(e) => return Err(e.into()),
        }
        let reflog = repo.reflog(STASH_REF)?;
        reflog
            .iter()
            .enumerate()
            .map(|(i, entry)| {
                let commit = repo.find_commit(entry.id_new())?;
                let message = entry.message().unwrap_or("").to_owned();
                Ok(StashEntry {
                    index: u32::try_from(i).unwrap_or(u32::MAX),
                    oid: commit.id().to_string(),
                    branch: branch_of(&message),
                    message,
                    time: entry.committer().when().seconds(),
                    base: commit.parent_id(0)?.to_string(),
                    has_untracked: commit.parent_count() >= 3,
                })
            })
            .collect()
    }

    /// The files of the listed stash `oid`; anything else is `RevisionNotFound`.
    pub fn stash_files(&self, oid: &str) -> Result<StashFiles, GitError> {
        let entry = self
            .list_stashes()?
            .into_iter()
            .find(|e| e.oid == oid)
            .ok_or_else(|| GitError::RevisionNotFound(oid.to_owned()))?;
        let tracked = self.commit_files(&entry.oid)?;
        let untracked_oid = if entry.has_untracked {
            let w = self.repo().find_commit(Oid::from_str(&entry.oid)?)?;
            Some(w.parent_id(2)?.to_string())
        } else {
            None
        };
        let untracked = match &untracked_oid {
            Some(u) => self.commit_files(u)?,
            None => Vec::new(),
        };
        Ok(StashFiles { tracked, untracked, untracked_oid })
    }

    /// `git stash push [--include-untracked] [-m <message>]`; a blank message is none.
    pub fn stash_push(&self, message: Option<&str>, include_untracked: bool) -> Result<(), GitError> {
        self.ensure_born()?;
        self.ensure_clean()?;
        self.ensure_no_conflicts()?;
        let before = self.stash_tip();
        let mut args = vec!["push"];
        if include_untracked {
            args.push("--include-untracked");
        }
        if let Some(m) = message.filter(|m| !m.trim().is_empty()) {
            args.extend(["-m", m]);
        }
        let output = self.run_stash(&args)?;
        if !output.status.success() {
            return Err(operation_failed("stash", &output));
        }
        // git exits 0 with "No local changes to save"; the ref is the reliable signal.
        if self.stash_tip() == before {
            return Err(GitError::NothingToStash);
        }
        Ok(())
    }

    pub fn stash_apply(&self, index: u32, oid: &str) -> Result<StashOutcome, GitError> {
        self.apply_like("apply", index, oid)
    }

    /// As apply; on conflicts git keeps the stash.
    pub fn stash_pop(&self, index: u32, oid: &str) -> Result<StashOutcome, GitError> {
        self.apply_like("pop", index, oid)
    }

    pub fn stash_drop(&self, index: u32, oid: &str) -> Result<(), GitError> {
        self.ensure_stash(index, oid)?;
        let output = self.run_stash(&["drop", &stash_ref(index)])?;
        if output.status.success() { Ok(()) } else { Err(operation_failed("stash", &output)) }
    }

    fn apply_like(&self, verb: &str, index: u32, oid: &str) -> Result<StashOutcome, GitError> {
        self.ensure_stash(index, oid)?;
        self.ensure_clean()?;
        self.ensure_no_conflicts()?;
        let output = self.run_stash(&[verb, &stash_ref(index)])?;
        self.stash_outcome(&output)
    }

    /// `StaleStash` unless `stash@{index}` is `oid`.
    fn ensure_stash(&self, index: u32, oid: &str) -> Result<(), GitError> {
        let current = self.list_stashes()?.into_iter().nth(index as usize);
        match current {
            Some(e) if e.oid == oid => Ok(()),
            _ => Err(GitError::StaleStash),
        }
    }

    fn ensure_no_conflicts(&self) -> Result<(), GitError> {
        if self.fresh_index()?.has_conflicts() { Err(GitError::UnresolvedConflicts) } else { Ok(()) }
    }

    fn stash_tip(&self) -> Option<Oid> {
        self.repo().refname_to_id(STASH_REF).ok()
    }

    fn run_stash(&self, args: &[&str]) -> Result<Output, GitError> {
        let (git, workdir) = self.git()?;
        git_ops::run(&git, workdir, "stash", args, &[])
    }

    fn stash_outcome(&self, output: &Output) -> Result<StashOutcome, GitError> {
        if output.status.success() {
            Ok(StashOutcome::Applied)
        } else if self.fresh_index()?.has_conflicts() {
            Ok(StashOutcome::Conflicts)
        } else {
            Err(operation_failed("stash", output))
        }
    }
}

fn stash_ref(index: u32) -> String {
    format!("stash@{{{index}}}")
}

/// "On <b>: …" / "WIP on <b>: …" → `<b>`; "(no branch)" and anything else → `None`.
fn branch_of(message: &str) -> Option<String> {
    let rest = message.strip_prefix("WIP on ").or_else(|| message.strip_prefix("On "))?;
    let (branch, _) = rest.split_once(':')?;
    (branch != "(no branch)" && !branch.is_empty()).then(|| branch.to_owned())
}
```

```ts
type StashRequest =
  | { action: "push"; message: string | null; includeUntracked: boolean }
  | { action: "apply" | "pop" | "drop"; index: number; oid: string };

/** The outcome of an apply or pop; null for push and drop. */
function execute(repoId: RepoId, req: StashRequest): Promise<StashOutcome | null> {
  switch (req.action) {
    case "push":
      return stashPush(repoId, req.message, req.includeUntracked).then(() => null);
    case "apply":
      return stashApply(repoId, req.index, req.oid);
    case "pop":
      return stashPop(repoId, req.index, req.oid);
    case "drop":
      return stashDrop(repoId, req.index, req.oid).then(() => null);
  }
}

export function useStashActions(repoId: RepoId): UseStashActions {
  const queryClient = useQueryClient();
  const [notice, setNotice] = useState<StashNotice | null>(null);
  const mutation = useMutation<StashOutcome | null, AppError, StashRequest>({
    mutationFn: (req) =>
      execute(repoId, req).catch((e: unknown) => {
        throw toAppError(e);
      }),
    // Runs on failure too: a refused apply may have changed nothing, a stale one needs the new list.
    onSettled: () => queryClient.invalidateQueries({ queryKey: queryKeys.repo(repoId) }),
  });
  const { mutateAsync } = mutation;
  const run = (req: StashRequest): Promise<AppError | null> => {
    setNotice(null);
    return mutateAsync(req).then(
      (outcome) => {
        if (outcome === "conflicts" && (req.action === "apply" || req.action === "pop")) {
          setNotice({ kind: req.action, index: req.index });
        }
        return null;
      },
      (e: AppError) => e,
    );
  };
  return {
    push: (message, includeUntracked) => run({ action: "push", message, includeUntracked }),
    apply: ({ index, oid }) => run({ action: "apply", index, oid }),
    pop: ({ index, oid }) => run({ action: "pop", index, oid }),
    drop: ({ index, oid }) => run({ action: "drop", index, oid }),
    pending: mutation.isPending,
    error: mutation.error,
    notice,
    clearError: mutation.reset,
    clearNotice: () => setNotice(null),
  };
}
```

```ts
): Gate {
  if (status === undefined || state === undefined) return { disabled: true };
```

```tsx
export function StashSummary({ repoId, oid }: StashSummaryProps) {
  const { stashes, error: listError, refetch } = useStashes(repoId);
  const { files, error: filesError, refetch: refetchFiles } = useStashFiles(repoId, oid);
  const entry = stashes?.find((s) => s.oid === oid);
  const untrackedOid = files?.untrackedOid ?? null;

  /** Clears the stash selection and any file opened from this stash. */
  const vanish = useCallback(() => {
    const { selected, select, selectStash } = useWorkspace.getState();
    const scoped = selected[repoId];
    const from = scoped ? commitOf(scoped.scope) : null;
    if (from !== null && (from === oid || from === untrackedOid)) select(repoId, null);
    selectStash(repoId, null);
  }, [repoId, oid, untrackedOid]);

  const gone =
    (stashes !== undefined && entry === undefined) || filesError?.kind === "revisionNotFound";
  useEffect(() => {
    if (gone) vanish();
  }, [gone, vanish]);

  if (listError !== null) return <RepoError error={listError} path={null} onRetry={refetch} onDismiss={close} />;
  if (entry === undefined) return <p role="status">Loading stash…</p>; // also shown for the one render before `vanish` runs
  return <Details … />;
}
```
